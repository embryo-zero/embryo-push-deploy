# Embryo Push Deploy

Embryo Push Deploy is Embryo-Zero's fork of [dokku](https://github.com/dokku/dokku) (b39ff6c, commit b39ff6c). It does deploy apps with git push.

- Our changes live on the `embryo` branch. The original license files (LICENSE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
